# Отзывы на сайте: подключение (один раз, ~15 минут)

Сейчас сайт работает в **демо-режиме**: отзыв сохраняется только в браузере автора и никуда не уходит.
Чтобы отзывы приходили Наталье в Telegram с кнопками «Одобрить / Отклонить», нужно один раз подключить `worker.js`.
Всё бесплатно (Cloudflare Workers и KV, лимиты с большим запасом).

## 1. Telegram-бот
1. В Telegram откройте @BotFather, команда `/newbot`, придумайте имя. Получите **токен** (`TG_TOKEN`).
2. Наталья открывает этого бота и нажимает **Start** (иначе бот не сможет ей писать).
3. Чтобы узнать её **chat id** (`TG_CHAT_ID`), пусть она напишет боту @userinfobot, он ответит числом.
   Решения по кнопкам принимает только этот id, чужие нажатия игнорируются. 
   695625210
   

## 2. Cloudflare Worker
1. Зарегистрируйтесь на cloudflare.com, раздел **Workers & Pages → Create → Worker**, вставьте код из `worker.js`, нажмите Deploy.
2. **Storage → KV → Create namespace** (например, `reviews`). В настройках воркера: **Bindings → KV namespace**, имя переменной строго `REVIEWS`.
3. В **Settings → Variables and Secrets** добавьте:
   - `TG_TOKEN`: токен бота;
   - `TG_CHAT_ID`: id Натальи;
   - `TG_SECRET`: любая длинная случайная строка (латиница и цифры);
   - `ALLOW_ORIGIN`: адрес сайта, например `https://natallia-palermo.com` (пока домена нет, можно `*`).
4. Запомните адрес воркера вида `https://reviews.<ваш-аккаунт>.workers.dev`.

## 3. Привязать бота к воркеру (один раз)
Откройте в браузере (подставьте свои значения):

```
https://api.telegram.org/bot<TG_TOKEN>/setWebhook?url=https://<адрес-воркера>/telegram&secret_token=<TG_SECRET>
```
Должно ответить `{"ok":true,...}`.

## 4. Подключить сайт
В `site/index.html` найдите строку

```js
const REVIEWS_API = "";
```
и вставьте адрес воркера: `const REVIEWS_API = "https://reviews.<аккаунт>.workers.dev";`

## Как это работает потом
- Гость отправляет отзыв, Наталье приходит сообщение с текстом и двумя кнопками.
- **Одобрить**: отзыв появляется на сайте (кэш до минуты). **Отклонить**: исчезает.
- Защита: скрытое поле для ботов, не чаще одного отзыва в минуту с одного адреса, длина ограничена, текст на сайте выводится безопасно.
- Если нужно удалить уже опубликованный отзыв, правится ключ `approved` в KV (Workers → KV → reviews).
